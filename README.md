# 💰 Expense Tracker (Python + CSV)                      
     
A simple command-line **Expense Tracker** built using **Python and CSV** file handling.                
         
---        
   
          
              
## ✅ Features                
- Add new expenses with date, category, amount, and description    
- View all expenses with total calculation  
- Search expenses by category       
- Stores all data in `expenses.csv` file       
                                                     
---                   
                      
## 🛠 Technologies Used          
- Python       
- CSV module    
- File Handling      
   
---  

## ▶️ How to Run  
   
```
python expense_tracker.py.  
``` 

Data is saved in `expenses.csv` in the same folder.

---

## 📂 Files Included

- `expense_tracker.py` — Main script  
- `expenses.csv` — Stores data  
- `README.md` — Project description
